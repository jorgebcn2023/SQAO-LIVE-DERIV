# SQAO GPT Multimodal Analyzer

This module is designed to combine SQAO quantitative data with user-supplied chart images.

## Contract

Inputs:
- Optional `DATA/live_analysis.json` generated by SQAO.
- One or more chart images, preferably D1, H1, M15, M5 and M1.

The GPT layer must:
1. Read all supplied timeframes together.
2. Preserve timeframe labels and avoid inventing unreadable values.
3. Distinguish observed chart facts from inferred scenarios.
4. Return `LONG`, `SHORT`, `WAIT` or `NO_TRADE`.
5. Report confidence as a model estimate, never as a historical win rate unless backtest evidence is supplied.
6. Explicitly flag missing/stale/inconsistent charts.
7. Never claim certainty or guaranteed profitability.

## API security

Store `OPENAI_API_KEY` in the Codespace secret/environment. Never commit the key to Git.
